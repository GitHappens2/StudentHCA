# Project Information
**Title:** UNT Student Healthcare Access  
**Description:**  
A healthcare access app for college students that helps users find  
nearby in-network providers based on their insurance and type of care needed, including  
primary care, dental, women’s health, mental health, urgent care, and other services like  
rating the clinic and doctor, and potentially notifications about blood drives (and other free  
healthcare related events, like flu-shots).
